# Darkstar

Darkstar is a colour palette that's a descendant of
[Solarized](https://ethanschoonover.com/solarized/).

## Design goals

1. **Every colour is readable as text**<br />
   Every colour reaches at least WCAG AA against the background.
2. **Real bright variants**<br />
   Every colour has a "bright" variant which is a brighter version of itself
   rather than a grey.
3. **Feel like Solarized**<br />
   Solarized's hues are preserved in the accent colours so that the palette
   feels familiar if you're used to Solarized.
