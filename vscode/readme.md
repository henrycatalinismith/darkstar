# Darkstar

Deep space colour palette

![VS Code using the Darkstar theme, with the Explorer sidebar open on a small TypeScript project and cart.ts in the editor showing syntax-highlighted functions and a doc comment](https://henry.catalinismith.se/darkstar/vscode/darkstar.webp)

Darkstar is one of
[Solarized](https://ethanschoonover.com/solarized/)'s many descendants. If you
love Solarized, but sometimes get tired of the contrast problems, Darkstar might
be for you.
